# Ideal Gas Law + Boltzmann Simulator

A lightweight browser-based educational simulator for first-year chemistry students.

## Features

- Interactive Ideal Gas Law controls (`PV = nRT`) for moles, volume, and temperature.
- Real-time pressure calculation in kPa and atm.
- Maxwell-Boltzmann speed distribution chart that updates with temperature and gas species.
- Dynamic particle animation that changes qualitative speed with mean molecular speed.
- Preset gases with different molar masses (He, N₂, O₂, CO₂).

## Run locally

Open `index.html` directly in a browser, or serve with a static server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
